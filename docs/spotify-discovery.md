# Spotify Discovery in Declan

## Configured defaults
- Categories: Country, Braai, Romantic, Sexy Time, Rock, Afrikaans, 80s, 90s, Work Focus, ADHD Focus and Massage.
- Automatic approval of Spotify search results.
- 25 playlists maximum per category, excluding any manually pinned favourites above the limit.
- Weekly refresh (every seven days after integration setup), plus manual refresh.
- Favourites persist across refreshes. Exclusions take precedence over favourites.
- Discovery never sends Spotify content to an AI model.

## Spotify credentials
Create a Spotify developer application and place a private file at
`/config/declan_spotify_credentials.json`:

```json
{"client_id": "YOUR_CLIENT_ID", "client_secret": "YOUR_CLIENT_SECRET"}
```

Do not commit this file. Spotify may limit API access depending on developer
app mode and account eligibility. If Spotify rejects playlist search, the
refresh fails without replacing the existing library.

## Home Assistant actions
Refresh all categories:

```yaml
action: declan_local.refresh_music_categories
```

Pin a playlist (replace the example with a real URI):

```yaml
action: declan_local.manage_music_playlist
data:
  category: adhd_focus
  operation: favourite
  playlist: spotify:playlist:ABCDEFGHIJKLMNOPQRSTUV
```

Exclude a playlist:

```yaml
action: declan_local.manage_music_playlist
data:
  category: massage
  operation: exclude
  playlist: spotify:playlist:ABCDEFGHIJKLMNOPQRSTUV
```

Play a category:

```yaml
action: declan_local.play_music_category
data:
  category: 90s
  room: everywhere
```

Voice examples after installing: "play 80s music everywhere", "play 90s
music in kitchen", "play ADHD focus music in bedroom", "play work focus music
in lounge", "play massage music in bedroom", "play Afrikaans music everywhere".

## Operational caveats
- The weekly refresh does not automatically run at installation. Trigger one
  manual refresh to populate a new library.
- Existing `/config/declan_music_playlists.json` playlist lists are imported
  as favourites on first use to avoid losing curated favourites.
- Discovery is keyword-based. Automatic approval can include imperfect matches;
  use exclusions to reject them permanently.
- New playlists are not generated by Spotify. Declan discovers existing public
  playlists through Spotify search and passes URIs to Music Assistant.
- API access, playback, voice commands and the weekly scheduler require live
  Home Assistant validation. No deployment is performed by this PR.
